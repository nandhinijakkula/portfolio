# Nandhini Jakkula — Portfolio

## Files
- `index.html` — portfolio page
- `style.css` — design and responsive layout
- `script.js` — mobile navigation
- `resume.pdf` — add your own PDF resume with this exact filename

## Publish with GitHub Pages
1. Create a GitHub account/repository.
2. Upload these files.
3. Add your resume as `resume.pdf`.
4. Go to **Settings → Pages**.
5. Choose **Deploy from a branch**, select `main` and `/root`, then Save.
6. GitHub will provide your live portfolio URL.

## Before publishing
Replace the placeholder GitHub and LinkedIn links in `index.html` with your real profile URLs. Replace project GitHub links with your actual repositories.
